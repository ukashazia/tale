# Phase 9 performance evidence

Run date: 2026-08-05. Command:

```text
cargo bench --locked --bench phase9 -- --noplot
```

Runner: Apple M1 Pro, 8 cores, macOS 26.6 (25G72),
`aarch64-apple-darwin`. Toolchain: rustc 1.97.1
(`8bab26f4f`, LLVM 22.1.6). Criterion collected 100 samples per benchmark;
the p95 values below are the 96th sorted per-iteration sample from the
Criterion sample files. Values are not cross-runner claims.

The largest fixture generators use fixed fictional values and are separated
from rendering. The flow benchmark uses the bounded 250,000-message input and
the production checked/cancellable aggregator.

## Memory evidence

The automated retained-state check runs ten identical task-history cycles,
evicts completed tasks to the configured maximum, and verifies the 256 KiB
per-task detail cap. It also exercises cancellation and generation discard.
The required reference-runner peak resident-memory measurement and component
attribution were not available from this environment without a platform
measurement runner. That measurement remains an explicit release blocker; no
arbitrary RSS pass threshold is invented here.
