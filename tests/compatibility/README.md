# Compatibility fixture review

The manifests in the adjacent version/platform fixture directories are the
compatibility ledger used by the automated suite. They are fictional or
mechanically redacted, identify the exact command and argument vector, and are
reviewed for names, addresses, IDs, domains, paths, and keys.

The current repository contains only the Linux Tailscale 1.98.9 fixture family.
It does not make a macOS or Windows support claim. A new client/platform family
requires a new manifest, fixtures, DTO contract review, and a complete matrix
run before it can be listed as Supported.
